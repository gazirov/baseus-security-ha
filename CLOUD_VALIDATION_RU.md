# Прямой Baseus/XM API — проверка 18.09.2026

## Подтверждено на реальном аккаунте

1. Пользователь успешно выполнил `login` из Python. Первая попытка с опечаткой
   в email вернула `100207`; с исправленным адресом сервер выдал `data.auth`.
   Это наблюдение этой проверки, а не универсальная расшифровка кода `100207`.
2. `devices`: подписанный discovery-запрос к
   `https://root.xmitech.net/v1/api/app/host` вернул региональный XM endpoint.
   Запрос `GetUserDeviceList` к `ipc-bu-ru-gw.baseussecurity.com` успешно вернул S1.
3. `device`: `GetUserDevice` для выбранных `sn` и `product` успешно вернул
   данные и `device_extend.platform` с DID, service string, P2P-паролем и wake key.
4. `wake`: `GetUserMQTTS` выдал MQTT-конфигурацию. Python подключился по TLS,
   подписался, отправил `WatchDevice` и получил ответ с тем же `seq`,
   `actionId=WatchDevice`, `result=true`.

Перед MQTT-проверкой приложение Baseus на планшете принудительно закрыто через
ADB. Сама команда `wake` не обращается к планшету/ADB и не открывает видеосессию.
Ответ WatchDevice подтверждает команду на уровне протокола, но не приём нового
видеокадра и не измеренное физическое состояние камеры.

Время успешной MQTT-проверки: **23:12:47 UTC+5**, 18.09.2026.
Ключи/пароли в отчёт не включены. Токен находится только в локальном session.json.

## Что осталось для кадра без планшета

Нужно самостоятельно установить XM/PPCS-соединение с DID/service string и
P2P-паролем, пройти авторизацию устройства, запустить видеоканал, выделить
видеопакеты и декодировать новый кадр. Существующий Python-клиент этого не делает.

Реальные ответы содержат `p2p_connect=122`. В `GetUserDeviceList` указано H.264,
а в `GetUserDevice` — H.265: нельзя выбрать декодер исключительно по одной
облачной записи. Кодек потребуется определить по параметрам/данным live-сессии.

Камера находится в другой подсети. Это не мешает уже проверенным HTTP/MQTT,
но для проверки локальных RTSP/ONVIF потребуется маршрут к её LAN-адресу
или диагностический компьютер непосредственно в её сети. Доступность этих
интерфейсов пока не установлена. Альтернативный путь — XM/PPCS через интернет.
